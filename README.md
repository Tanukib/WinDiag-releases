# WinDiag - downloads

Pacotes oficiais do **WinDiag**, diagnóstico e reparo do Windows para leigos.

- `latest.json`: versão mais recente, nome do pacote e SHA-256 (lido pelo instalador e pelo botão "Procurar atualização").
- `WinDiag-vX.Y.Z.zip`: o pacote completo.

## Instalar

Baixe e dê duplo clique no `Instalar-WinDiag.bat` (ele baixa o pacote, confere o SHA-256 e instala), ou extraia o ZIP e rode o instalador de dentro dele.

O WinDiag não tem assinatura digital: o Windows pode mostrar o aviso do SmartScreen. Clique em **Mais informações** e depois em **Executar assim mesmo**.
